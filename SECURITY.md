# Crakbit Core Security

Crakbit Native v0.1 is pre-mainnet engineering software. Do not use it for real-value funds.

Security-sensitive areas include consensus serialization, RandomX seed selection, target arithmetic, block linkage, monetary issuance, treasury accounting, future transaction validation, wallet key handling, networking and release integrity.

Please report suspected security issues privately to the Crakbit Society maintainers rather than publishing a working exploit against an active network.

Mainnet remains blocked until the native implementation has deterministic cross-platform consensus vectors, fuzzing, multi-node testing, reproducible release builds and independent review.
